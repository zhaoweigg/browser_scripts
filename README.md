# browser_scripts

Personal Tampermonkey userscripts.

| Script | What it does |
| --- | --- |
| [quiet-video-controls.user.js](quiet-video-controls.user.js) | Stops HBO Max from dimming the video when the player controls appear on mouse move. Controls still show as usual. Toggle with Alt+Shift+Q or the Tampermonkey menu. |
| [speaker-skip.user.js](speaker-skip.user.js) | Adds a button to YouTube's player that skips every part where one chosen person talks (set up for 伍雷 on 三個水槍手). Needs the local helper in [speaker-skip/](speaker-skip/). |
