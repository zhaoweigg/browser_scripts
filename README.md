# browser_scripts

Personal Tampermonkey userscripts.

| Script | What it does |
| --- | --- |
| [quiet-video-controls.user.js](quiet-video-controls.user.js) | Stops HBO Max (and similar players) from showing controls and dimming the video on mouse move. Controls appear only after a click or keypress. Toggle with Alt+Shift+Q or the Tampermonkey menu. |
